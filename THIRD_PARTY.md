# Third-party components and references

- **Playwright Core 1.63.0** — Microsoft, Apache-2.0. Installed from npm using the committed lockfile. Its package includes its license/notice. [Source](https://github.com/microsoft/playwright).
- **byJoey/fanout** — architecture and integration reference, MIT, Copyright 2026 Joey (byJoey). No fanout source is copied or executed. [Project and license](https://github.com/byJoey/fanout).
- **VPN Gate** — external volunteer-node directory queried on demand. Directory access does not verify residential status, availability or country-association effects. [Official project](https://www.vpngate.net/en/).
- **monosans/proxy-list** and **Proxifly/free-proxy-list** — external public proxy candidate lists, fetched as data from their fixed GitHub sources. No third-party executable is installed. Source country and ASN metadata do not prove availability or residential status. [monosans](https://github.com/monosans/proxy-list) · [Proxifly](https://github.com/proxifly/free-proxy-list).
- **country.is** — external IP-country lookup used through the user-selected proxy. Independent of Google's region logic. [Project](https://country.is/).
